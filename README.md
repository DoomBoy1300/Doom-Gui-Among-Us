Doom Menu

A modified build of HydraMenu for Among Us with the in-game GUI branding changed from HydraMenu to Doom Menu.

✨ Changes

- Renamed the GUI display name from "HydraMenu" to "Doom Menu"
- Internal HydraMenu namespaces and class names were left unchanged
- Based on the original HydraMenu DLL

📦 Installation

1. Download "DoomMenu.dll" from the repository's Releases or file list.
2. Back up your existing mod files.
3. Place "DoomMenu.dll" in the appropriate folder for your Among Us mod setup.
4. Launch Among Us and verify that the GUI displays Doom Menu.

HydraMenu

Doom Menu
